
# 🚀 Isthmic: Domainer Enterprise Suite

**Isthmic** هو الحل المتكامل لإدارة دورة حياة الأصول الرقمية (النطاقات)، مصمم للمستثمرين المؤسسيين والشركات التي تبحث عن ميزة تنافسية مدعومة بالذكاء الاصطناعي.

## 🌟 الهوية والرسالة
تم بناء Isthmic ليكون "مركز قيادة" وليس مجرد أداة بحث. يقوم النظام بربط كافة مراحل الاستثمار في النطاقات في واجهة موحدة مدعومة بنظام وكلاء Gemini 3.

## 🏗️ معمارية النظام (2025 Architecture)
- **Core:** React 19 + TypeScript.
- **AI Engine:** Google GenAI SDK 1.38+.
- **Agents:**
  - **Strategic:** Master Brain (التخطيط المالي).
  - **Sourcing:** Discovery & Drop Sniper (اكتشاف الفرص).
  - **Operations:** Pipeline & Portfolio (إدارة الأصول).
  - **Liquidation:** Negotiation & Marketplace (تسييل المحفظة).
- **Persistence:** LocalStorage Ledger System لضمان استمرارية البيانات محلياً.

## 🛠️ كيف تبدأ؟
1. **تثبيت المتطلبات:** `npm install`
2. **إعداد البيئة:** تأكد من توفر `process.env.API_KEY`.
3. **التشغيل:** `npm run dev`

## 📊 القدرات الرئيسية
- **التدقيق الجنائي:** فحص تاريخ النطاق، العلامات التجارية، والسيولة.
- **توليد الهوية:** إنشاء شعارات وفلسفات براندينج فورية باستخدام Gemini 2.5 Flash.
- **رادار المزادات:** متابعة السيولة العالمية في الوقت الحقيقي.

## ⚖️ الخصوصية
كافة بياناتك، مفاتيح الـ API، ومحافظك مخزنة محلياً في متصفحك. لا يوجد خادم وسيط يجمع بياناتك الاستثمارية.
