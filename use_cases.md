# Isthmic Pro — Operational Use Cases

This document outlines the core operational workflows supported by the Isthmic Pro Sovereign Engine.

---

## 1. Alpha Mine (Discovery & Audit)

**Objective:** Identify high-value market signals and emerging trends across multiple data tiers.

**Use Cases:**
- **Cross-Tier Signal Aggregation:** A user configures the Alpha Mine to pull data simultaneously from Early Signals (e.g., HackerNews, GitHub Trending) and Money Signals (e.g., CrunchBase, SEC Edgar) to identify startups gaining both developer traction and funding.
- **Weighted Source Analysis:** A user adjusts the source weights (e.g., setting Patents=4 and Funding=5) to prioritize deep-tech innovations with significant financial backing over general media hype.
- **Optimization Loop Tuning:** A user sets the optimization loop parameters (e.g., target_score=0.85, recency_days=60) to filter out stale data and focus only on highly relevant, recent market movements.
- **Domain Availability Filtering:** A user activates the `.COM Only` filter to ensure that any identified trends or brand opportunities have viable, top-tier domain names available.

---

## 2. Brand Intel (Smart Intelligence)

**Objective:** Synthesize high-prestige, phonetically resonant brand identities based on market intelligence.

**Use Cases:**
- **Rapid Niche Branding:** A user selects the "Cyber Security" quick template. The Brand Forge automatically populates the niche ("Zero-Trust Defense Systems") and seed keywords ("shield, guard, cipher, lock") to generate relevant brand names.
- **Custom Identity Synthesis:** A user inputs a highly specific Market Niche and custom Seed Keywords. The Hybrid Markov-AI Synthesis Protocol generates a list of unique brand identities, scoring them on phonetic resonance and semantic alignment.
- **Secure Brand Generation:** The user verifies the "Secure Protocol" indicator is active, ensuring that the brand generation process is utilizing the encrypted BYOK connection to the Gemini API.

---

## 3. Profile (Identity)

**Objective:** Manage user sovereignty, API keys, and external tool integrations.

**Use Cases:**
- **BYOK (Bring Your Own Key) Configuration:** A new user navigates to the Profile section to securely input their personal Gemini API key. This ensures their AI usage is billed to their own account and their prompts remain private.
- **Custom Tool Integration:** A user configures their API keys for external intelligence tools like Estibot (for domain valuation), Semrush (for SEO data), and USPTO (for trademark checks), integrating these capabilities directly into their Isthmic Pro workflow.

---

## 4. Admin (System Control)

**Objective:** Oversee system health, security integrity, and user access (Restricted to Admin roles).

**Use Cases:**
- **System Integrity Audit:** An administrator reviews the "Integrity" tab to verify the status of the Firewall, Quantum Encryption, and Sovereign Shield, ensuring the system has not been compromised.
- **Performance Monitoring:** An administrator checks the "Military Brief" tab to monitor real-time Vault Health and Network Load metrics, ensuring the system is operating within optimal parameters.
- **User Access Management:** An administrator uses the "User Management" tab to review active sessions, elevate a standard user to an Admin role, or revoke access for a compromised account.
